📋 재생목록 ID 찾는 방법

  1. YouTube 재생목록 페이지로 이동
  2. URL에서 list= 뒤의 문자열이 재생목록 ID입니다
  3. 예: youtube.com/playlist?list=PLxxxxxxxxxxxxx
